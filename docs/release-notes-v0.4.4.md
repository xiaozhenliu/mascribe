# MaScribe v0.4.4

## 中文

**MaScribe v0.4.4** — 设置界面焕新、连接测试与菜单优化

**主要更新：**

- **设置界面全面升级** — 重新设计的标签式布局，左侧导航清晰分区（基础设置 / AI 引擎 / 提示词 / 视觉识别 / 词典）。语言切换从下拉菜单改为一键中英切换按钮，操作更直观。设置窗口更大更舒适，提示词输入框自适应填满可用空间。
- **AI 润色 API 连接测试** — 在线 API 和 Ollama 本地模型均支持连接测试，配置完成后一键验证是否可用，减少排错时间。
- **状态栏菜单优化** — 新增"关于"菜单项，可直接查看当前版本号和 Git 构建信息；退出菜单前添加分隔线，防止误触关闭应用。

**升级说明：** 无需修改配置。升级后首次打开设置页会看到全新界面，之前的设置项和 API 密钥均保留不变。

---

## English

**MaScribe v0.4.4** — Settings Redesign, API Connection Test & Menu Improvements

**Highlights:**

- **Settings page redesigned** — New tab-based layout with left-side navigation (Basic / AI Engine / Prompt / Vision / Dictionary). Language switching replaced with a one-tap ZH|EN toggle button. Larger, more comfortable settings window with prompt textarea that fills available space.
- **AI Polish API connection test** — Both online API and local Ollama models support one-click connection testing, so you can verify your configuration works before using it.
- **Status bar menu improvements** — New "About" menu item displays the current version and Git build info. A separator above "Quit" prevents accidental app closure.

**Upgrade notes:** No configuration changes required. The new settings layout is applied automatically — all existing settings and API keys are preserved.
