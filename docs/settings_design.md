# 设置页面重新设计方案

**文档版本**: 1.0  
**创建日期**: 2026-05-03  
**状态**: 设计阶段  
**目标**: 重新设计设置页面，采用横向布局和分tab显示

---

## 设计方案概述

基于当前设置页面的内容分析，我建议采用**左侧垂直tab导航+ 右侧内容区域**的横向布局。

### 当前问题分析

1. **垂直滚动过长**：10个设置项需要大量滚动
2. **双重滚动冲突**：AI润色提示词的textarea在滚动容器内，造成操作困扰
3. **信息密度低**：单列布局未充分利用屏幕宽度
4. **缺乏分组**：所有设置混在一起，难以快速定位

### Tab 分组方案

我建议将设置分为 **4个tab**：

#### 1️⃣ **基础设置 (Basic / 基础)**
- 全局快捷键
- 录音目录

#### 2️⃣ **AI 润色 (AI Polish / AI润色)**
- AI 润色引擎选择（关闭/本地模型/在线API）
- 在线 API 设置（endpoint、key、model、测试连接）
- 本地模型设置（GGUF路径）
- AI 润色提示词（textarea）

#### 3️⃣ **视觉增强 (Vision / 视觉)**
- 屏幕 OCR（关闭/系统内置/Ollama OCR）
- OCR 设置（endpoint、model）
- 截图上下文（关闭/仅保存/发送到API）

#### 4️⃣ **纠错词典 (Dictionary / 词典)**
- 纠错词典（添加规则、规则列表）

### 布局结构设计

```
┌─────────────────────────────────────────────────────────┐
│  Settings[语言选择器]      │← 固定顶部栏
├──────────┬──────────────────────────────────────────────┤
│          │                                              │
│  基础    │                                              │
│          │                                              │
│  AI润色  │         Tab 内容区域                         │
│          │      （根据选中的tab显示对应内容）            │
│  视觉    │                                              │
│          │                                              │
│  词典    │                                              │
│          │                                              │
├──────────┴──────────────────────────────────────────────┤
│[保存]按钮     │ ← 固定底部栏
└─────────────────────────────────────────────────────────┘
```

### 详细布局规格

**整体尺寸：**
- 窗口建议最小宽度：800px
- 窗口建议最小高度：600px

**左侧Tab导航栏：**
- 宽度：140px（固定）
- 背景色：#fafafa
- 右边框：1px solid #e8e8ed
- Tab项样式：
  - 高度：48px
  - 内边距：12px 16px
  - 字体大小：13px
  - 未选中：背景透明，文字 #6e6e73
  - 选中：背景 #fff，文字 #0071e3，左侧3px蓝色边框
  - Hover：背景 #f0f0f5

**右侧内容区域：**
- 宽度：flex: 1（占据剩余空间）
- 内边距：32px
- 背景色：#fff
- 可滚动（overflow-y: auto）
- 最大内容宽度：600px（居中显示）

**顶部栏：**
- 高度：64px（包含macOS标题栏空间）
- 背景：#f5f5f7
- 底边框：1px solid #e8e8ed
- 布局：标题居左，语言选择器居右

**底部操作栏：**
- 高度：64px
- 背景：#fff
- 顶边框：1px solid #e8e8ed
- 保存按钮居右对齐

### 响应式考虑

当窗口宽度 < 700px 时：
- Tab导航栏改为顶部横向tab
- 内容区域占据全宽
- 保持垂直滚动

### 交互设计

1. **Tab切换**：点击左侧tab项切换内容，带淡入淡出动画（150ms）
2. **保存按钮**：始终可见，固定在底部
3. **滚动优化**：每个tab的内容独立滚动，避免双重滚动
4. **焦点管理**：切换tab时，自动滚动到顶部

`★ Insight─────────────────────────────────────`
**设计要点：**
1. **分组逻辑**：按功能域分组（基础/AI/视觉/词典），而非按技术实现分组
2. **减少滚动**：每个tab内容量控制在1-2屏内，AI润色tab可能需要轻微滚动（因为有textarea）
3. **横向利用**：左侧导航固定140px，右侧内容最大600px居中，充分利用宽屏空间

## 实现优先级

**Phase 1 - 核心结构**（必须）
- 实现左侧tab导航栏
- 实现右侧内容区域切换
- 实现顶部栏和底部操作栏
- 基本的tab切换功能

**Phase 2 - 内容迁移**（必须）
- 将现有设置项迁移到对应tab
- 保持现有功能逻辑不变
- 确保数据绑定正确

**Phase 3 - 交互优化**（推荐）
- 添加tab切换动画
- 优化滚动体验
- 添加焦点管理

**Phase 4 - 响应式**（可选）
- 实现窗口宽度 < 700px 时的横向tab布局
- 移动端适配（如果需要）

## 技术实现建议

1. **HTML结构**：
   - 使用 `<nav>` 标签包裹tab导航
   - 使用 `data-tab` 属性标识tab内容区域
   - 保持现有的表单元素和ID不变

2. **CSS实现**：
   - 使用 Flexbox 布局（左侧固定宽度 + 右侧flex: 1）
   - 使用 `.active` 类控制tab选中状态
   - 使用 `.hidden` 类控制内容显示/隐藏
   - 添加 `transition` 实现平滑切换

3. **JavaScript逻辑**：
   - 添加tab切换事件监听
   - 保持现有的设置加载/保存逻辑
   - 添加tab状态管理（记住用户上次选择的tab）

4. **兼容性**：
   - 保持与现有 TypeScript 代码的兼容
   - 不破坏现有的国际化（i18n）系统
   - 确保所有现有功能正常工作
